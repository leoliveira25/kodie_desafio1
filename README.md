# 🎬 Tá Ligado

## Análises de novelas, séries e filmes

O **Tá Ligado** é uma Landing Page desenvolvida para o Desafio 01: Tire sua Ideia do Papel.

O projeto apresenta a proposta de um site especializado em análises de novelas, séries e filmes.

A ideia é ajudar o público a compreender melhor as produções audiovisuais por meio de análises de roteiro, personagens, atuações e direção.

---

## 🎯 Objetivo

Criar uma Landing Page:

- responsiva;
- acessível;
- visualmente organizada;
- publicada no GitHub Pages;
- desenvolvida utilizando HTML5 e CSS3.

---

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Inteligência Artificial como ferramenta de apoio

## 🧱 Estrutura da página

O projeto possui as seguintes seções:

### Header

Apresenta a identidade do Tá Ligado e o menu de navegação.

### Hero

Apresenta a proposta principal do projeto, uma descrição e botões de chamada para ação.

### Sobre

Explica o conceito e o objetivo do Tá Ligado.

### Análises

Apresenta três categorias de conteúdo:

* Filmes
* Séries
* Novelas

### Critérios

Apresenta quatro critérios utilizados para analisar uma produção:

* Roteiro
* Personagens
* Atuações
* Direção

### Galeria

Apresenta imagens relacionadas ao universo audiovisual.

### Contato

Disponibiliza um canal de contato para o visitante.

### Footer

Apresenta informações finais e links de navegação.

---

## ♿ Acessibilidade

Foram aplicadas algumas boas práticas de acessibilidade:

* idioma da página definido como português do Brasil;
* hierarquia de títulos;
* navegação semântica;
* textos alternativos nas imagens;
* uso de `aria-label` quando necessário;
* links identificáveis;
* suporte para usuários que preferem reduzir animações;
* layout adaptado para diferentes tamanhos de tela.

---

## 📱 Responsividade

O projeto utiliza:

* CSS Grid;
* Flexbox;
* Media Queries;
* `clamp()`;
* unidades relativas.

Foram definidos comportamentos específicos para:

* Desktop;
* Tablet;
* Celular.

O objetivo é evitar rolagem horizontal e manter a página utilizável em diferentes dispositivos.
